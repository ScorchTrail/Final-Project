# Stock Portfolio Application

**Author:** Vedant Patel

A console-based Java application that simulates a brokerage account. Users can deposit and withdraw cash, buy and sell stocks, and view their transaction history and current portfolio holdings.

## Features

- **Deposit Cash** — adds a CASH DEPOSIT transaction with cost basis 1.00
- **Withdraw Cash** — adds a CASH WITHDRAW transaction (qty stored as negative); blocked if insufficient funds
- **Buy Stock** — records a BUY transaction and automatically deducts cash via a WITHDRAW transaction; blocked if insufficient cash
- **Sell Stock** — records a SELL transaction and automatically credits cash via a DEPOSIT transaction; blocked if insufficient shares
- **Display Transaction History** — prints all transactions in a formatted table
- **Display Portfolio** — aggregates all transactions to show current holdings per ticker
- **Input Validation** — invalid menu choices and non-numeric amounts show an error and re-prompt instead of crashing
